You'll find here a collection of third-party integrations for Fish-Networking in other assets, as well as assets that work well with FishNet.

> **Info:** If you have a contribution you would like to add to this page, please feel free to open a pull-request on the [documentation repository](https://github.com/FirstGearGames/FishNet-Documentation) or leave us a [suggestion](https://github.com/FirstGearGames/FishNet/discussions).

The following resources are put together by developers such as yourself. The Fish-Networking team has no official involvement in these resources, thus we may not be able to troubleshoot or resolve any issues you experience with them.

## Asset Integrations

[MetaVoiceChat](https://assetstore.unity.com/packages/tools/audio/metavoicechat-free-proximity-voice-chat-for-fishnet-mirror-netcode-249789) is a completely free, simple, and self-contained proximity voice chat solution for Unity's popular client-server networking libraries with all of the features you need.

[Dissonance Voice Chat](https://assetstore.unity.com/packages/tools/audio/dissonance-voice-chat-70078) is a real-time Voice over IP (VoIP) system designed to be built directly into Unity games. [Dissonance Voice Chat for Fish-Networking](https://github.com/LambdaTheDev/DissonanceFishNetIntegration) is a community integration for using it with FishNet, provided by [LambdaTheDev](https://github.com/LambdaTheDev) and the creator of Dissonance.

[FishNet Multi-Room Manager](https://github.com/oaStaticGames/FishNet-Multi-Room-Manager) is a lightweight, single-process multi-room solution for FishNet that allows you to host multiple isolated game rooms on one server using Unity's additive scenes and FishNet's built-in scene-based visibility. Players connect to a central lobby, where they can view active rooms, create new ones, and join existing rooms. Each room runs in its own additive scene with completely isolated network traffic.

[Turtle Pass](https://assetstore.unity.com/packages/tools/network/turtle-pass-fishnet-large-data-sender-230513) allows you to send large byte arrays over several frames to prevent data from overwhelming bandwidth limited transports like Steam and Unity Transport.

[Network Audio Sync](https://assetstore.unity.com/packages/tools/network/network-audio-sync-fishnet-231103) is an easy way to synchronize audio clips over the network.

[Master Server Toolkit](https://assetstore.unity.com/packages/tools/network/master-server-toolkit-71604) is a powerful solution to many back-end problems you may encounter when developing multiplayer games or applications. It includes user registration and authorization, game server list, user data management, database interactions, chats and chat channels. A Fish-Networking demo is included!

[Network Particle System](https://assetstore.unity.com/packages/tools/network/network-particle-system-for-fishnet-234203) will synchronize particles, lifespan, and more.

[GameKit for Fish-Networking](https://assetstore.unity.com/packages/tools/network/gamekit-for-fish-networking-220140) is an efficient solution to managing inventory, chat, and several other common multiplayer game mechanics. GameKit is well commented and is intended to be used as a learning resource.

[ParrelSync](https://github.com/VeriorPies/ParrelSync) allows you to run multiple editors of the same project, making multiplayer testing easier.

[MultiPlay](https://assetstore.unity.com/packages/tools/utilities/multiplay-open-multiple-unity-editors-192177) lets you open multiple Unity editor windows to test multiplayer games without building every time.

[Facepunch.Steamworks](https://github.com/Facepunch/Facepunch.Steamworks) is a C# wrapper on top of Valve's Steamworks library.

[Steamworks.NET](https://steamworks.github.io/) is a C# Wrapper for Valve's Steamworks API, it can be used either with Unity or your C# based application.

[Toolkit for Steamworks 2025](https://assetstore.unity.com/packages/tools/integration/toolkit-for-steamworks-sdk-2021-246552) is a powerful set of tools, systems and editor extensions to make your integration with the Steam API easier, faster, and more robust.

[Steamworks Foundation](https://assetstore.unity.com/packages/tools/integration/steamworks-foundation-246551) is a free, limited version of Toolkit for Steamworks.

[Fish-Networking-Discovery](/docs/v4/asset-integrations/fish-network-discovery) is a simple LAN network discovery component for Fish-Networking.

[Vault Inventory](https://assetstore.unity.com/packages/tools/game-toolkits/vault-inventory-223607) supports your design requirements from Editor to Runtime with an intuitive designer dashboard and runtime UI components for a smooth multiplayer inventory experience.

[Edgegap](https://edgegap.com/unity-plugin)'s Unity plugin makes game server hosting and orchestration easy and simple.

[PlayFlow Cloud](https://www.playflowcloud.com/) simplifies multiplayer game server hosting. Use the PlayFlow Cloud Unity Plugin to spin up multiplayer game servers for your Unity game.

[Crayon: Multiplayer Coloring & Voting Game Template](https://assetstore.unity.com/packages/templates/systems/crayon-multiplayer-coloring-voting-game-template-fishnet-273977) is a Unity Asset Store template designed for multiplayer coloring and voting gameplay.

[COZY: Stylized Weather 3](https://assetstore.unity.com/packages/tools/utilities/cozy-stylized-weather-3-271742) is a customizable weather system offering dynamic time-of-day cycles, seasonal transitions, and diverse atmospheric effects. It has a multiplayer module that supports FishNet: [COZY: Link - Multiplayer Module](https://assetstore.unity.com/packages/tools/utilities/cozy-link-multiplayer-module-280997).

[Master Audio 2024: AAA Sound](https://assetstore.unity.com/packages/tools/audio/master-audio-2024-aaa-sound-5607) is a powerful audio framework for Unity, offering real-time parameter commands, full multiplayer functionality, and advanced occlusion features. It integrates seamlessly with FishNet.

[Multiplayer for Malbers Character Controller](https://assetstore.unity.com/packages/tools/network/multiplayer-for-malbers-character-controller-fishnet-254448) is a networking integration for Animal Controller, designed to work with FishNet. It extends MalberS to support multiplayer functionality with minimal workflow changes.

[Smooth Sync](https://assetstore.unity.com/packages/tools/network/smooth-sync-96925) is a network synchronization tool for Unity that enhances object movement across multiplayer sessions. It improves NetworkTransform by offering better configurability, reduced bandwidth usage, and smoother, more accurate syncing for Rigidbodies and Transforms.

## Transports

There are a variety of transports that can be implemented in your project for uses such as WebGL, Steam, Unity Relay, and more. For a complete collection see: [Transports](/docs/v4/transports).
